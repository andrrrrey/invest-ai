**Краткое описание:**
Веб-приложение для управления инвестиционными проектами с AI-анализом и финансовым моделированием. Позволяет создавать заявки трёх типов — инвестиционные, операционные и смарт-контракты, автоматически рассчитывать финансовые метрики (NPV, IRR, DCF, DPP, PI, LTV/CAC), Value Score и маршрут решения для операционных заявок, генерировать AI-описания, оценку рисков, AI-скоринг и аналитику аномалий. AI-функции работают через переключаемых провайдеров (OpenAI, Anthropic Claude, RouterAI). Приложение управляет жизненным циклом проектов (draft → pending_approval → approved/rejected) с историей статусов, ведёт план/факт исполнения с прогнозами и AI-комментариями, транши финансирования с триггер-чеклистами и историей, комментарии, вложения (документы), уведомления, экспорт отчётов в PDF/Excel. Включает ролевую модель (CEO, CFO, Manager, Owner), JWT-авторизацию, саморегистрацию с подтверждением по email и восстановление пароля.

## 3. Краткая архитектура

**Описание архитектуры:**
Двухзвенная архитектура: фронтенд (статический HTML + Alpine.js) отдаётся через Nginx, который также работает как reverse proxy для FastAPI-бэкенда (в production статика может отдаваться и самим FastAPI через StaticFiles). Бэкенд предоставляет REST API (версионированное /api/v1/) с разбивкой на роутеры: проекты, финансы, AI, статистика, настройки, аутентификация, пользователи, экспорт, комментарии, вложения, уведомления, транши, факт (план/факт). Финансовые расчёты дублируются: real-time на фронтенде через vanilla JS и серверная валидация на бэкенде через numpy-financial. AI-функции инкапсулированы в ai_service с переключаемым провайдером (OpenAI / Anthropic / RouterAI), выбор и API-ключи хранятся в файловом settings_store (/data/settings.json) с приоритетом переменных окружения. Данные хранятся в SQLite (dev) или PostgreSQL (prod); загруженные аватары и вложения хранятся на диске (/data/avatars, /data/attachments). Приложение контейнеризировано через Docker Compose (backend + nginx).

**Основной стек:**

| Слой | Технология |
|------|-----------|
| Backend | Python 3.11, FastAPI, SQLAlchemy 2, Pydantic 2, Uvicorn, Alembic |
| База данных | SQLite (dev, aiosqlite) / PostgreSQL (prod) |
| AI | Переключаемые провайдеры: OpenAI (gpt-5.4), Anthropic Claude (claude-sonnet-4-6), RouterAI (routerai.ru, по умолчанию anthropic/claude-sonnet-4.5) |
| Финансовые расчёты | numpy-financial + numpy (backend), vanilla JS (frontend) |
| Аутентификация | JWT (python-jose), passlib + bcrypt |
| Хранение файлов | Файловая система (аватары, вложения), JSON-файл настроек |
| Экспорт | WeasyPrint (PDF), openpyxl (Excel) |
| Frontend | HTML5, Alpine.js 3, Font Awesome |
| Веб-сервер | Nginx 1.25 (reverse proxy + static) |
| Контейнеризация | Docker, Docker Compose |
| Email | SMTP (отправка паролей при регистрации, восстановление пароля) |

## 10. Локальное тестирование

**Тестировался ли сервис локально:**

- [x] Да
- [ ] Нет

**Как запускался:**

1. **Docker Compose (основной способ):**
   ```bash
   cp .env.example .env
   # Отредактировать .env: добавить OPENAI_API_KEY
   docker compose up -d
   # Приложение: http://localhost, API docs: http://localhost/api/docs
   ```

2. **Без Docker (для разработки):**
   ```bash
   cd backend
   python -m venv .venv && source .venv/bin/activate
   pip install -r requirements.txt
   uvicorn app.main:app --reload --port 8000
   # Frontend: cd frontend && python -m http.server 3000
   ```

**Какие ресурсы использовались:**

- Внутренние: SQLite (встроенная БД, не требует отдельного сервера), файловое хранилище (/data: аватары, вложения, settings.json)
- Внешние: AI-провайдер на выбор — OpenAI / Anthropic / RouterAI (для AI-функций), CDN (Alpine.js, Font Awesome)
