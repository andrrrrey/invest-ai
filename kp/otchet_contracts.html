7Маршрут согласования
✓ Выполнено

C&B → Заказчик → Казначей Coin → Финансовый директор

Баффет уведомляет каждого согласующего по очереди. В личном сообщении есть кнопки «Согласовать» и «На доработку». Пока предыдущий согласующий не принял решение, контракт дальше не идёт. При возврате на доработку комментарий обязателен, после исправления маршрут начинается заново.

Если этап висит больше двух суток, Баффет напоминает о нём.

В карточке видно текущий этап, у кого контракт, дату отправки, решения и комментарии. На вкладке «История» — все изменения полей в формате «было → стало» и все согласования.

Где: Карточка контракта → блок «Согласование» и вкладка «История»

13Проект приказа (ЛНА) по контракту
✓ Выполнено

По согласованному контракту одной кнопкой формируется проект приказа в .docx по скиллу «Постановка задач через ЛНА, план работ и приказ»:

  • фирменный формат ПравоТеха;
  • приложение «План работ»: этапы контракта превращаются в задачи по формуле «результат — срок — критерий — ресурсы — подтверждение»;
  • заметки для юриста.

Баффет рассылает документ на согласование: C&B → Юрист → CEO. При возврате на доработку загружается исправленный файл, и маршрут запускается заново.

Где: Карточка согласованного контракта → «Сформировать проект приказа»

4Что нужно сделать для начала работы

  1. Назначить согласующих: Настройки → «Роли согласования» — C&B, казначей Coin, юрист (финансовый директор и CEO подставляются автоматически, при необходимости их можно изменить). Без назначенных ролей контракт не отправится на согласование — система подскажет, кого не хватает.
  2. Установить курс Coin в разделе «Курс Coin» (по умолчанию действует прежнее значение 10,1 ₽).
  3. Подключить AI в Настройках, чтобы работали AI-помощник и формирование приказов через AI. Без AI система продолжает работать: проверки и документы собираются по шаблонам.
  4. Передать шаблон приказа о выделении денежных средств для инвест-проектов (п. 14) — заменим временный шаблон.
  5. Контракты, отправленные на согласование до обновления, рекомендуется отозвать в черновик и отправить заново, чтобы они прошли новый маршрут.

5Дополнительно

  • Уведомления по контрактам открывают нужную карточку контракта.
  • В PDF-отчёте по контракту отображаются названия и сроки всех этапов.
  • В разделе «Отчётность» контракты доступны и для отчёта по отдельному проекту.
  • Подтверждать выполнение этапов могут CFO и менеджер; все действия попадают в историю контракта.
